# Automated Time-Series Extraction Along a Railway Profile Using LiCSBAS

## Overview
This script automates the extraction of InSAR time-series displacement at a set of geographic locations along a railway profile using **LiCSBAS**. The geographic coordinates are read from `Locations_on_railway.txt`, and `LiCSBAS_cum2tstxt.py` is automatically executed for each location to extract the corresponding cumulative displacement time series from the LiCSBAS `cum.h5` dataset. The script sequentially reads the geographic coordinates and performs automated point-wise time-series extraction. This is useful for analyzing deformation along linear infrastructure such as railways, roads, pipelines, and tunnels.

## Prerequisites
- **Python Version**: Python 3 or higher.
- **LiCSBAS**: Must be installed and available in the system `PATH`. This includes `LiCSBAS_cum2tstxt.py` and its dependencies.
- **Input Data**: A valid LiCSBAS `cum.h5` file (cumulative displacement time-series) and a correctly formatted `Locations_on_railway.txt` file.
- **Coordinate Coverage**: The coordinates must fall within the spatial coverage of the LiCSBAS `cum.h5` dataset.
- **No additional Python libraries** are required beyond the standard library, as the script calls LiCSBAS tools via the system shell.

## Installation
1. Ensure LiCSBAS is installed and properly configured on your system. Refer to the official LiCSBAS documentation for installation instructions.
2. Place the script in the LiCSBAS processing directory that contains:
   ```text
   Locations_on_railway.txt
   TS_GEOCml/
   └── cum.h5
   ```
3. No further installation steps are needed. The script uses Python 3 and the existing LiCSBAS installation.

## Configuration
The script does not use a separate configuration file. Its behavior is determined by the input files and their locations:

- **`Locations_on_railway.txt`**: A tab-separated file containing geographic coordinates. The file is expected to have longitude and latitude values in separate tab-separated columns. The first line is assumed to be a header and is skipped during processing. Example:
  ```text
  Longitude    Latitude
  -98.1234    19.4567
  -98.1228    19.4571
  -98.1221    19.4578
  ```
- **`TS_GEOCml/cum.h5`**: The LiCSBAS cumulative displacement time-series file. This file must exist and be valid.
- **Output directory**: The resulting time-series text files are generated by `LiCSBAS_cum2tstxt.py` in the current working directory (or as configured within LiCSBAS). Ensure you have write permissions.

## How to Run
1. Ensure the script is placed in the correct directory (see Installation) and that `Locations_on_railway.txt` and `TS_GEOCml/cum.h5` are present.
2. Run the script from the command line:
   ```bash
   python3 script_name.py
   ```
3. The script will:
   - Open `Locations_on_railway.txt` and skip the header line.
   - For each subsequent line, parse the longitude and latitude.
   - Construct and execute the following command for each coordinate:
     ```bash
     LiCSBAS_cum2tstxt.py -g <longitude>/<latitude> -i TS_GEOCml/cum.h5
     ```
   - The resulting time-series text files are generated by `LiCSBAS_cum2tstxt.py`.
4. Check the output files in the directory where `LiCSBAS_cum2tstxt.py` writes them (typically the current directory).

## Code Explanation
The script is intentionally simple and sequential:
- **Reading coordinates**: It reads `Locations_on_railway.txt`, ignores the first line (header), and processes each remaining line.
- **Parsing**: Longitude and latitude are extracted from tab-separated columns.
- **Execution**: For each coordinate, it calls `LiCSBAS_cum2tstxt.py` with the `-g` option (geographic coordinate as `longitude/latitude`) and `-i` option (input `cum.h5` file).
- **Sequential processing**: The script does not parallelize; it processes coordinates one by one. This is suitable for a moderate number of points along a linear profile.
- **Use case**: The method is useful for analyzing deformation along linear infrastructure such as railways, roads, pipelines, and tunnels.

## Troubleshooting
- **LiCSBAS not found**: Ensure `LiCSBAS_cum2tstxt.py` is in your system `PATH`. You can test by running `LiCSBAS_cum2tstxt.py --help` in the terminal.
- **Missing input files**: Verify that `Locations_on_railway.txt` and `TS_GEOCml/cum.h5` exist in the expected locations.
- **Coordinate format errors**: Ensure the file is tab-separated and contains only numeric longitude and latitude values. The first line must be a header.
- **Coordinates outside coverage**: If a coordinate falls outside the spatial coverage of `cum.h5`, `LiCSBAS_cum2tstxt.py` may produce an error or empty output. Check the LiCSBAS log for details.
- **Permission issues**: Ensure you have write permission in the output directory.
- **LiCSBAS errors**: Consult the LiCSBAS documentation and log files for issues related to `cum.h5` or `LiCSBAS_cum2tstxt.py`.
