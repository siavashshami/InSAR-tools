# Automated Time-Series Extraction Along a Railway Profile Using LiCSBAS

# Description

This script automates the extraction of InSAR time-series displacement at a set of geographic locations along a railway profile using LiCSBAS.

The geographic coordinates are read from Locations_on_railway.txt, and LiCSBAS_cum2tstxt.py is automatically executed for each location to extract the corresponding cumulative displacement time series from the LiCSBAS cum.h5 dataset.

Input
Locations_on_railway.txt — Tab-separated geographic coordinates.
TS_GEOCml/cum.h5 — LiCSBAS cumulative displacement time-series file.

The coordinate file is expected to contain longitude and latitude values in separate tab-separated columns.

Example:

Longitude    Latitude
-98.1234    19.4567
-98.1228    19.4571
-98.1221    19.4578
Output

For each coordinate, the script calls:

LiCSBAS_cum2tstxt.py -g <longitude>/<latitude> -i TS_GEOCml/cum.h5

The resulting time-series text files are generated by LiCSBAS_cum2tstxt.py.

Requirements
Python 3
LiCSBAS installed and available in the system PATH
A valid LiCSBAS cum.h5 file
A correctly formatted Locations_on_railway.txt
Usage

Place the script in the LiCSBAS processing directory containing:

Locations_on_railway.txt
TS_GEOCml/
└── cum.h5

Then run:

python3 script_name.py
Method

The script sequentially reads the geographic coordinates and performs automated point-wise time-series extraction. This is useful for analyzing deformation along linear infrastructure such as railways, roads, pipelines, and tunnels.

Notes

The script assumes that the first line of Locations_on_railway.txt is a header and therefore starts processing from the second line.

The coordinates must fall within the spatial coverage of the LiCSBAS cum.h5 dataset.

Reference

LiCSBAS: An open-source software package for processing and analyzing LiCSAR Sentinel-1 InSAR time-series data.
